Drop fan art images straight into this folder — .jpg, .jpeg, .png, .gif, .webp, or .avif.

The site pulls this folder automatically on every page load (via the GitHub API), so there is nothing to edit in index.html. Just add files here and push.

Display order is randomized on every load — the gallery reshuffles itself each time someone visits, so there's no need to name files in any particular order.
